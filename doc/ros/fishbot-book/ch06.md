# ch2.怎么在 launch 里加 --arg 给 xacro 传参数

## 核心说明
`xacro` 命令支持 `--arg name:=value` 来传参数，放到 launch 的 `Command` 列表里即可。

> 
> 语法：`xacro model.xacro --arg param1:=val1 --arg param2:=val2`

## 写法1：硬编码参数（固定值）

```py
from launch.substitutions import Command, LaunchConfiguration

robot_description = ParameterValue(
    Command([
        'xacro',
        LaunchConfiguration('model'),
        '--arg', 'wheel_radius:=0.08',
        '--arg', 'laser_offset_x:=0.15'
    ]),
    value_type=str
)
```

## 写法2：把xacro参数也做成launch启动参数（推荐，外部可覆盖）

比如我们想在启动时可自定义轮子半径：

```py
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import Command, LaunchConfiguration
from launch_ros.parameter_descriptions import ParameterValue

# 1. 声明launch参数，供外部传入
arg_model = DeclareLaunchArgument(
    name='model',
    default_value='robot.urdf.xacro',
    description='xacro模型路径'
)
arg_wheel_radius = DeclareLaunchArgument(
    name='wheel_radius',
    default_value='0.08',
    description='驱动轮半径'
)
arg_laser_x = DeclareLaunchArgument(
    name='laser_x',
    default_value='0.15',
    description='激光相对base_link x偏移'
)

# 2. 传给xacro --arg
robot_description = ParameterValue(
    Command([
        'xacro',
        LaunchConfiguration('model'),
        '--arg', ['wheel_radius:=', LaunchConfiguration('wheel_radius')],
        '--arg', ['laser_offset_x:=', LaunchConfiguration('laser_x')]
    ]),
    value_type=str
)
```

### 启动时，命令行覆盖参数示例

```sh
ros2 launch robot_nav_bringup robot_bringup.launch.py wheel_radius:=0.1 laser_x:=0.2
```

## 在xacro文件里面接收参数（robot.urdf.xacro）

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="shturl.cc/Fa1CAXFcCLJy058g9vg">
  <!-- 声明参数，接收launch传进来的值 -->
  <xacro:arg name="wheel_radius" default="0.08"/>
  <xacro:arg name="laser_offset_x" default="0.15"/>

  <link name="base_link">
    <visual>
      <origin xyz="${laser_offset_x} 0 0.1" rpy="0 0 0"/>
      <geometry>
        <cylinder radius="${wheel_radius}" length="0.1"/>
      </geometry>
    </visual>
  </link>
</robot>
```

## ⚠️ 重要坑点

1. **`xacro:arg` 是xacro层面参数，不是ROS节点参数**
   - 由 `xacro` 命令在展开URDF阶段解析；
   - 一旦URDF生成完成，运行时不能动态修改，必须重新launch。
2. 列表拼接规则

```
'--arg', ['wheel_radius:=', LaunchConfiguration('wheel_radius')]
```

launch会自动拼接成字符串：`--arg wheel_radius:=0.08`
3. 不要写 `'--arg wheel_radius:='` 这种带空格的字符串，容易出shell解析问题，拆成列表元素是最佳实践。
